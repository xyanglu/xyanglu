### LLM Eval Toolkit

### Interview Copilot
- Source: https://github.com/xyanglu/interview-copilot
- Real-time interview assistant: mic audio to streaming on-device transcription (RealtimeSTT/faster-whisper + VAD) to LLM-generated talking points pushed to a phone browser over FastAPI + WebSocket. ~4s end-to-end latency; audio stays on-device except the LLM API call.
